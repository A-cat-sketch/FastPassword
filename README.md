# FastPassword
FastPassword 是一款纯本地、开源、零网络依赖的轻量级离线密码管理器。基于 Python 和 wxPython 构建，专为追求极致安全与便携的用户设计。绝对开源，保证你的密码不会被上传。你的所有密码都将被高强度加密，并可以随身存储在 U 盘中，真正实现“数据在自己手里，密码只属于自己”。
✨ 核心特性

🔒 军工级安全：采用 Argon2id 算法生成强密钥，结合 AES-256-GCM 认证加密算法，即使 U 盘丢失，捡到者也无法破解你的密码。

💾 极致便携：无需安装，无需数据库，摒弃笨重的云端同步。一个 exe 程序，一个加密文件，插上 U 盘即可在任何 Windows 电脑上使用。

🌐 零网络依赖：完全离线运行，隔绝网络黑客攻击、云服务泄露等风险。你的数据从不离开你的设备。

📝 轻量纯粹：不使用数据库，直接采用“内存字典 + 加密 JSON”的设计，体积小巧，读写极速。

🛡️ 安全机制说明

主密码绝不落地：每次加解密都在内存中完成，绝不写入任何文件。

随机盐与 Nonce：每次保存都生成全新的随机盐和 Nonce，防止重放攻击，确保相同密码每次加密结果都不同。

数据完整性校验：GCM 模式内置认证标签，哪怕加密文件被篡改一个字节，解密也会直接失败。

⚠️ 重要警告
主密码是解锁数据的唯一凭证。一旦遗忘，神仙难救，请务必牢记并定期备份 U 盘中的加密文件！
